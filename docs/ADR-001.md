# ADR-001: HyperFrames single-file continuous world untuk film 3 menit

Status: Accepted (approval Schnee, 2026-10-04)

## Konteks
Film OWC 82s sebelumnya dibangun di Remotion (repo remotion-owc-upi). Rebuild 180s memakai framework HyperFrames dengan aset/fisika/kamera proven dari bank v4.

## Keputusan
1. **Framework:** HyperFrames 0.8.x (HTML+GSAP→MP4 deterministik), CLI pinned per proyek.
2. **Arsitektur:** single-file `index.html` continuous world — bukan nested sub-composition. Kamera kontinu translate+scale pada wrapper `#world` 6720×2160 digerakkan satu master GSAP timeline. Nested composition memutus kontinuitas kamera antar scene.
3. **Fisika:** port murni JS dari BANK-EXTRACT (chamberSurfY dual-harmonik, thetaTable precompute O(1), rpmFromV). Tanpa Math.random/Date.now.
4. **Tipografi:** 5 gaya caption (bl/tr/bc/tl/strip) port 1:1 dari Film.tsx.
5. **Audio:** 12 VO segmen Edge TTS + ocean/hiss bed ducking pasca-render (loudnorm -16 LUFS), bukan mixing di framework.
6. **Verifikasi:** lint → check → snapshot → render ×2 sha identik → ffprobe → decode null → stills.
7. **Repo:** private `Schnee111/owc-hyperframes`, Day-0 scaffold di main (README/docs/LICENSE), semua runtime via branch feat + PR + Sentinel, full `--merge` setelah approval.

## Konsekuensi
- Kamera tidak pernah "locked" — glide kontinu seperti r7-r9 Remotion.
- Determinisme byte-identik memungkinkan double verification murah.
- Repo Remotion lama tetap arsip; tidak dihapus.
